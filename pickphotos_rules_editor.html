规则优先级：先看「具体日期规则」，再回落到「常规周规则」。
· 日期规则勾选全天时，当天整体按该类型走，忽略周规则。
· 日期规则只填时间段时，仅在该时段内覆盖；其余时间回落周规则。
· 同一天有多条日期规则时，列表中靠下的覆盖靠上的。
· 比例筛选、GPS 筛选、文件名时间提取都在时间筛选阶段生效。

文件名时间提取（可选）

很多相机/手机以拍摄时间命名文件（如 IMG_20231015_143022.jpg）。 启用后，在 EXIF 拍摄时间不可用时，尝试从文件名解析时间。
启用
解析方式
文件名模板
占位符：%Y 年（4 位）、%m 月、%d 日、 %H 时、%M 分、%S 秒、 * 匹配任意字符。
匹配是子串匹配，前缀（如 IMG_）和后缀会被自动忽略， 所以模板只要写时间部分即可。
例如模板 %Y%m%d_%H%M%S 能匹配 IMG_20231015_143022.jpg、Screenshot_20231015_143022.png 等；
模板 %Y-%m-%d_%H-%M-%S 能匹配 DSC00012_2023-10-15_14-30-22.JPG 等；
如果需要限定前缀（比如只想匹配 IMG_ 开头的），可以写 IMG_%Y%m%d_%H%M%S。
自动识别会尝试以下常见格式：YYYYMMDD_HHMMSS、 YYYY-MM-DD_HH-MM-SS、YYYYMMDDHHMMSS、 YYYY-MM-DD（时间补 00:00:00）、Unix 秒/毫秒时间戳。 识别到的时间会按 YYYY-MM-DD HH:MM:SS 使用。

GPS 位置筛选（可选）

按拍摄地点筛选。坐标支持十进制度和度分秒两种输入方式，内部统一按十进制度计算。半径单位米。仅对非工作时间拍摄的图片生效。
依赖 exiftool：比例筛选和 GPS 筛选都需要 exiftool 命令行工具读取图片元数据。 使用前请确认在终端里执行 exiftool -ver 能返回版本号。
安装方式：Linux 执行 sudo apt install libimage-exiftool-perl； macOS 执行 brew install exiftool； Windows 下载 exiftool.exe 放到 PATH 目录下。 未安装时，脚本会报错退出，不会静默跳过这两项筛选。
启用
名称 格式 纬度 经度 半径（米）
度分秒示例：北京天安门约 N 39°54′27″ / E 116°23′17″； 十进制等价于 39.9075, 116.3881。
南纬、西经请选择 S / W，数值本身填正值。
